📱 Campus Wallet

Campus Wallet is a MERN-based digital wallet platform designed for college campuses.
It allows students to manage their daily transactions, use a PayLater feature for small credit-based purchases, and interact with vendors seamlessly.
Admins can monitor transactions and manage users through a dedicated dashboard.

🚀 Tech Stack

Frontend: React (Vite), TailwindCSS

Backend: Node.js, Express.js

Database: MongoDB, Mongoose

Authentication: JWT, bcrypt

Other Tools: dotenv, cors, nodemon

🔑 Features

👨‍🎓 Student Wallet – Add, view, and spend balance

🛒 Vendor Payments – Pay vendors directly on campus

💳 PayLater – Small credit feature for emergency expenses

🛠 Admin Dashboard – Manage users, vendors, and transactions

🔐 Authentication – Secure login & signup with JWT

📊 Transaction History – Track all wallet activities
